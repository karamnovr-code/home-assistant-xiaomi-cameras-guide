# Security policy

This repository contains documentation and sanitized examples only.

Do not open an issue containing Xiaomi credentials, account/session values,
complete `xiaomi://` URLs, DID/MAC/IP/serial data, Home Assistant tokens,
Ingress URLs, personal hostnames, room or person names, dashboard dumps, or
camera frames.

Report vulnerabilities in go2rtc, Home Assistant, or Xiaomi products through
the channels published by their maintainers or vendors. This repository does
not maintain those products.
